This file contains selected query examples and explains the business meaning of each result.

The goal of this file is to show how the text project can answer practical questions about members, books, loans, payments, and library activity.

```text
queries/06_views_indexes_transactions.sql
```

Which members are the most active?

## 4. Revenue by Payment Type

Query source:

```text
queries/04_grouping_aggregates.sql
```

Business question:

How much revenue was generated by each payment type?

```text
SELECT
    payment_type,
    COUNT(*) AS total_payments,
    SUM(amount) AS total_amount,
    ROUND(AVG(amount), 2) AS average_amount
FROM payments
GROUP BY payment_type
ORDER BY total_amount DESC;
```

Business meaning:

This query summarizes payment revenue by category, such as late fees or membership fees.

## 5. Top Books by Category

Query source:

```text
queries/06_views_indexes_transactions.sql
```

Business question:

What are the top books within each category?

```text
SELECT
    category_name,
    title,
    total_loans,
    category_rank
FROM (
    SELECT
        cat.category_name,
        b.title,
        COUNT(l.loan_id) AS total_loans,
        RANK() OVER (
            PARTITION BY cat.category_name
            ORDER BY COUNT(l.loan_id) DESC
        ) AS category_rank
    FROM categories cat
    INNER JOIN book_categories bc
        ON cat.category_id = bc.category_id
    INNER JOIN books b
        ON bc.book_id = b.book_id
    LEFT JOIN copies c
        ON b.book_id = c.book_id
    LEFT JOIN loans l
        ON c.copy_id = l.copy_id
    GROUP BY cat.category_name, b.title
) ranked_books
WHERE category_rank <= 3
ORDER BY category_name, category_rank, title;
```

Business meaning:

This query uses a window function to rank books inside each category. It is useful for category-level popularity analysis.

## 6. Available Copies by Branch

Query source:

```text
queries/04_grouping_aggregates.sql
```

Business question:

Which branches have the most available book copies?

```text
SELECT
    br.branch_name,
    br.city,
    COUNT(c.copy_id) AS available_copies
FROM branches br
LEFT JOIN copies c
    ON br.branch_id = c.branch_id
   AND c.status = 'Available'
GROUP BY br.branch_id, br.branch_name, br.city
ORDER BY available_copies DESC;
```

Business meaning:

This query shows how many available copies each branch currently has. It can help compare branch inventory.

## 7. Books Without Reviews

Query source:

```text
queries/03_joins.sql
queries/05_subqueries.sql
```

Business question:

Which books have no reviews?

```text
SELECT
    b.book_id,
    b.title
FROM books b
LEFT JOIN reviews rv
    ON b.book_id = rv.book_id
WHERE rv.review_id IS NULL
ORDER BY b.title;
```

Business meaning:

This query helps identify books that have not received any member feedback yet.

## 8. Members With No Loans

Query source:

```text
queries/03_joins.sql
queries/05_subqueries.sql
```

Business question:

Which members have never borrowed a book?

```text
SELECT
    m.member_id,
    CONCAT(m.first_name, ' ', m.last_name) AS member_name,
    m.city
FROM members m
LEFT JOIN loans l
    ON m.member_id = l.member_id
WHERE l.loan_id IS NULL
ORDER BY m.member_id;
```

Business meaning:

This query identifies registered members who have not yet borrowed any books. It can be useful for engagement campaigns.
